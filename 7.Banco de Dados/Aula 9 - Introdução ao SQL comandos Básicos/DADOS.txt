2- Usando JOINs (combinar dados)

Usando JOINs para combinar dados
O objetivo deste exercício é praticar o uso de JOINs para combinar dados de duas ou mais tabelas.
1. Crie uma consulta SQL que use um JOIN para responder a cada uma das seguintes perguntas:

Quais são os clientes que compraram o produto mais caro?
SELECT TOP 3
    Clientes.Nome AS Cliente,
    Produtos.Nome AS Produto,
    Produtos.Preco AS Valor
FROM Clientes
INNER JOIN Pedidos
    ON Clientes.ClienteID = Pedidos.ClienteID
INNER JOIN Produtos
    ON Pedidos.ProdutoID = Produtos.ProdutoID
ORDER BY Produtos.Preco DESC;
----------------------------------------------------------

Quais são os produtos mais vendidos por cada cliente?
SELECT
    Clientes.ClienteID,
    Clientes.Nome AS Cliente,
    Produtos.ProdutoID,
    Produtos.Nome AS Produto,
    COUNT(*) AS QuantidadeComprada
FROM Clientes
INNER JOIN Pedidos
    ON Clientes.ClienteID = Pedidos.ClienteID
INNER JOIN Produtos
    ON Pedidos.ProdutoID = Produtos.ProdutoID
GROUP BY
    Clientes.ClienteID,
    Clientes.Nome,
    Produtos.ProdutoID,
    Produtos.Nome
ORDER BY
    Clientes.Nome,
    QuantidadeComprada DESC;
-------------------------------------------------------
Quais são as categorias com mais pedidos?
SELECT  
    Categorias.CategoriasID, 
    Categorias.Nome AS Categoria,
    COUNT(*) AS QuantidadeComprada
FROM Clientes
INNER JOIN Pedidos
    ON Clientes.ClienteID = Pedidos.ClienteID
INNER JOIN Produtos
    ON Pedidos.ProdutoID = Produtos.ProdutoID
INNER JOIN Categorias
    ON Produtos.CategoriaID = Categorias.CategoriasID
GROUP BY
    Categorias.CategoriasID,
    Categorias.Nome
ORDER BY
    QuantidadeComprada DESC;
--------------------------------------------------------------
