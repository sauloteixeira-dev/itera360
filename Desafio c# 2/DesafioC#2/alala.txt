
1. Criar o "Histórico" (As Classes/Modelos)

Você precisa criar duas estruturas para representar o que acontece na cancela:
• Passagem (Sucesso): É a caixinha que guarda os dados de uma cobrança que deu certo. Ela precisa ter:
	• O veículo que passou (pode ser uma classe Veiculo que você já tenha, ou uma string Placa).
	• A data e a hora exata da cobrança.
	• O valor do pedágio cobrado.
• TentativaPassagem (Falha): É uma caixinha especial para quando o motorista não tem saldo. Em vez de criar tudo do zero, você vai usar Herança (TentativaPassagem : Passagem). Isso significa que ela ganha automaticamente tudo o que a Passagem tem (veículo, data e valor), mas você vai adicionar um campo a mais:
	• Motivo (Ex: "Saldo Insuficiente").

2. Criar o "Banco de Dados" Temporário (Na classe Pedágio)

Dentro da sua classe Pedágio (que provavelmente já controla as cancelas ou os valores), você vai criar duas gavetas virtuais (Listas Estáticas) que vão guardar o histórico enquanto o programa estiver rodando:
• Uma lista para guardar todas as passagens de sucesso: static List<Passagem>
• Uma lista para guardar todas as tentativas falhas:
Por que estáticas (static)? Para que elas pertençam à classe Pedagio como um todo e não sumam ou se dupliquem a cada novo pedágio criado.

3. Mudar a Lógica da Cancela (Salvar os dados)

Você provavelmente já tem um método no seu código onde o veículo tenta passar pelo pedágio. Você vai modificar esse método para fazer o seguinte:
• Se o veículo tem saldo: O sistema desconta o dinheiro e, agora, cria um objeto new Passagem(...) com os dados daquela viagem e dá um .Add() na lista de sucessos.
• Se o veículo NÃO tem saldo: A cancela não abre, o sistema cria um objeto new TentativaPassagem(...) preenchendo o motivo como "Saldo Insuficiente", e dá um .Add() na lista de falhas.

4. Criar a Tela de Relatórios (LINQ e Menu)

Essa é a parte principal do exercício. Você vai atualizar o menu principal do seu console:
1. Adicione a opção "Relatórios" no menu principal.
2. Ao clicar nela, abre um Submenu com: 1 - Visualizar Passagens e 2 - Visualizar Tentativas.
3. Quando o usuário escolher uma das opções, você vai usar o LINQ para filtrar os dados antes de mostrar na tela.
O que é o LINQ?
Pense no LINQ como o "Google" ou o "Filtro do Excel" para as listas do C#. Em vez de fazer um monte de laços foreach e if manuais para achar um dado, você faz uma linha de comando elegante.
Por exemplo, para listar passagens ordenadas pela data mais recente, você usará algo como:
csharp
var passagensOrdenadas = listaPassagens.OrderByDescending(p => p.DataHora);
Use o código com cuidado.
Ou para buscar as falhas de um carro específico:
csharp
var falhasDoCarro = listaTentativas.Where(t => t.Veiculo.Placa == "ABC1234");
Use o código com cuidado.

Resumo do Fluxo de Trabalho sugerido:

1. Crie a classe Passagem e depois a TentativaPassagem herdando dela.
2. Abra a classe Pedagio e declare as duas listas List<> no topo dela.
3. Vá no método de cobrança do pedágio e coloque a linha de código que adiciona (.Add) o registro nas listas dependendo se o pagamento passou ou não.
4. Crie as funções de relatório usando Where ou OrderBy do LINQ e exiba os resultados com um foreach.
5. Monte o Menu no arquivo principal (Program.cs) para chamar essas funções.
